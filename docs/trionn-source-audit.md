# Trionn — source capture and fidelity status

Source: https://trionn.com/
Target: https://daniel-soliz.github.io/triunexa-digital/
Date: 2026-11-05

Two read-only browser inspection runs were completed:
- Desktop: https://agent.tinyfish.ai/runs/4251bd65-6902-4961-94bf-f2f812cfc734
- Requested mobile/missing states: https://agent.tinyfish.ai/runs/49f6d50a-68d7-4276-ac8c-db48d79d44d1

## Confirmed by the browser inspection
Hero dark background #0C0C0C; canvas-based central abstract symbol and thin geometric lines; pill controls; a right-hand white navigation panel with large navigation links; Lenis; project cards and a testimonial carousel. The rendered source is a JavaScript-driven studio site, not the same product as the TRIUNEXA directory.

## Missing evidence
The available remote browser has no supported viewport-size control, so 390x844 mobile capture was not possible. It can click, but the complete press-and-hold/release effect could not be observed. Captures are internal to the browser provider; no source screenshot files or shareable image URLs were exposed for a normalized visual comparison. Exact font files, layout metrics and the source canvas implementation were not retrieved.

The orange fish cursor reported by the provider is not accepted as a verified website asset: TinyFish also supports its own fish cursor, and the observations do not distinguish source content from injected automation UI.

## Implementation decision
No application changes based on Trionn were made. The previously completed emerald-core implementation remains published. No claim of a full Trionn clone, mobile match or complete effect reproduction is justified by the available evidence.

## Required next evidence
A desktop and mobile screen recording, covering the hero, press-and-hold/release interaction, scrolling sections, menu opening/closing and footer. Matching desktop/mobile screenshots should accompany it if exact typography and layout comparison is required. Alternatively, provide an environment capable of controlling the source viewport and capturing inspectable images.

Any future adaptation must preserve the TRIUNEXA catalogue, search, contact dossiers, links, PWA, owner-only ADM, feedback and company data. Use TRIUNEXA identity/content, not Trionn business claims, clients or testimonials.
